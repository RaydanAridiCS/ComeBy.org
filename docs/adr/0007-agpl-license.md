# 0007: AGPL-3.0 license

**Status:** accepted · 2026-10-17

## Context
Comeby is open source and hosted for free. We want contributions back and don't want closed copies of the hosted service.

## Decision
License the code under the GNU Affero General Public License v3.0.

## Consequences
Anyone can use, study and modify Comeby. Anyone who runs a modified version as a network service must publish their changes under the same license.
