# Security policy

Comeby holds guests' names, phone numbers and emails, so we take security seriously. How the app protects them is described in [docs/security.md](docs/security.md).

## Reporting a vulnerability

**Please don't open a public issue.** Email **security@comeby.org** with:

- what you found and where,
- steps to reproduce,
- the impact you think it has.

We'll acknowledge within 72 hours and keep you updated until it's fixed. We're happy to credit you once the fix ships.

## Scope

The hosted service at comeby.org and the code in this repository. Please don't run automated scanners against comeby.org, access other people's data, or disrupt the service.

Only the hosted service is supported. Copies that other people run are outside this policy, but if you find a flaw in the code itself, we want to hear about it. Fixes land on `main`; there are no maintained release branches.
